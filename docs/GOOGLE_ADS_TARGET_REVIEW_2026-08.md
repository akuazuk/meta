# Review campaign targets (Aug 2026 Google change)

**Reviewed:** 2026-08-05  
**Status:** DONE — цели сверены; для кампаний с over-performance применён режим **«жёсткая эффективность»** (цель ≈ факт 7д), чтобы после 17.08.2026 не потерять текущую отдачу.

Контекст: с 17.08.2026 budget-limited кампании с tCPA/tROAS будут ближе держаться **заявленной** цели. Если факт лучше цели и цель не обновить — Google может **ослабить** эффективность до цели.

## Как отметить review в UI

1. Recommendations / уведомление *Review your campaign targets*  
2. Bid Target Adjustment Tool (с 6 июля 2026)  
3. После наших правок целей — можно **Apply / Done** в инструменте, если ещё висит.

Уведомление может исчезнуть не сразу; факт review зафиксирован этим документом + обновлёнными targets в API.
