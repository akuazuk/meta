## 3. Быстрые команды

```bash
source .venv/bin/activate
python -m scripts.diagnose_blockers
python -m scripts.create_test_campaign --verify
```

Проверка блокеров – только чтение. `--verify` печатает живые статусы
(`ACTIVE` / `PAUSED`) и не падает, если кампания уже запущена.
