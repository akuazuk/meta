## Как коммитить, чтобы не пересечься

1. `git fetch origin main`.
2. Отдельный worktree от `origin/main`. Если в `/workspace` грязное дерево, его не трогать и чужие незакоммиченные файлы не коммитить.
3. Один файл или одна тема на коммит. Для правок этой инструкции коммитить только `docs/UROLOGIST_AGENT_HANDOFF.md`.
4. Не коммитить `.env` и `tmp_refs/`.
5. Не `amend` и не force-push.
6. Перед push: `git pull --rebase origin main`. Если push отклонён, историю не переписывать, вернуть ошибку.
7. Чужие кампании из этого файла не пересоздавать.
8. Новые правки дописывать новым датированным разделом в этот же файл.
